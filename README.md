🧱 Project Structure Example
src/main/java <br/>
└── com.company.project <br/>
    ├── config          # 공통 설정 (Filter / Interceptor) <br/>
    ├── controller      # API 엔드포인트 <br/>
    ├── service         # 비즈니스 로직 <br/>
    ├── repository      # DB 접근 계층 <br/>
    ├── dto             # 요청/응답 DTO <br/>
    ├── exception       # 전역 예외 처리 <br/>
    └── util            # 공통 기능 (인증, 업로드 등)
